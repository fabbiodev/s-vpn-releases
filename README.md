# S-VPN for Windows

Download the latest Windows build from [Releases](https://github.com/fabbiodev/s-vpn-releases/releases/latest).

S-VPN supports WireGuard and AmneziaWG profiles, TUN and Filter modes, Russian and English interfaces. Extract the complete archive and run S-VPN.exe. Requires .NET Runtime 10 x64.

This repository contains binary releases, SHA-256 checksums and a signed update feed. Application sources are kept in a separate private repository. Generated source archives from this repository contain this page only.

Starting with 0.7.0, S-VPN checks this repository for updates. Downloads are verified against an ECDSA-signed manifest and SHA-256 before installation. Update settings and notification preferences are in Settings > About. Install 0.7.0 manually once when upgrading from an older version.

Third-party licenses and upstream source links are included in the application archive. A compiled application can be inspected or decompiled; private source hosting does not prevent reverse engineering.
